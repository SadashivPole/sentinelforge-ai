# Public Interactive Demo

## Overview

The public interactive demo is a static website hosted on GitHub Pages that demonstrates SentinelForge's detection capabilities using **synthetic, precomputed data only**.

## Data

- **Source:** Synthetic security events only — no real logs, no local data access
- **Scenarios:** failed login burst, password spraying, suspicious PowerShell, suspicious process tree, C2-beacon-like traffic
- **Labeling:** All results are clearly labeled as precomputed
- **Live detection:** The public demo does **not** perform real-time browser-based detection

## What It Is Not

- Not connected to the local SOC dashboard
- Not connected to the SQLite database
- Not running live detection rules
- Not processing real security logs
