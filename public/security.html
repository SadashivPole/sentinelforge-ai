Security & privacy

Design decisions and honest limitations for the local dashboard and public demo.

Localhost-only binding

The dashboard binds to 127.0.0.1 only by default — never 0.0.0.0.

No wildcard CORS

Same-origin access only. No cross-origin exposure.

No shell execution

No arbitrary shell execution or filesystem path traversal from the dashboard.

No credentials in source

Configuration uses SENTINELFORGE_* environment variables only.

Sanitized errors

Error messages exclude raw event data.

Read-only endpoints

All dashboard endpoints are read-only — no state-changing operations.

Prototype — not production

SentinelForge is an open prototype, not a production SIEM. It is not a hosted service and does not provide real-time SOC monitoring.
