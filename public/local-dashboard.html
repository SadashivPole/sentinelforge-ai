Local SOC dashboard

Run the SentinelForge dashboard locally on localhost, backed by the Python detection engine and SQLite storage.

What the dashboard is

The SentinelForge local dashboard is a read-only HTTP server written in Python. It binds to 127.0.0.1 only and serves a simple web interface over SQLite data produced by the CLI detection engine. It is not a hosted service, not exposed to the internet, and not part of the public website.

Prerequisites

  • Python 3.12 or newer
  • SentinelForge installed from source (pip install .)
  • A SQLite database produced by the CLI (sentinelforge ingest ...)

Start the dashboard

# Start on the default address (127.0.0.1:8080)
sentinelforge dashboard

# Or specify a custom database path
sentinelforge dashboard --db-path /path/to/your/sentinelforge.db

# Custom host/port (localhost only)
sentinelforge dashboard --host 127.0.0.1 --port 9090

Available routes

Security defaults

  • Binds to 127.0.0.1 only — never 0.0.0.0
  • Read-only endpoints only — no state-changing operations
  • No wildcard CORS — same-origin access only
  • Error messages exclude raw event data
  • All filter values use parameterized SQL queries

CLI vs dashboard

The dashboard shares the same SQLite database and Python detection engine as the CLI. Events ingested via sentinelforge ingest appear in the dashboard immediately.

Not a production SIEM. This is a local-first prototype for demonstration and development use.
