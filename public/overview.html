Platform overview

SentinelForge AI is a demonstrable SOC detection engineering platform for analysts, detection engineers, threat hunters, and blue-team learners.

A local-first detection engineering platform

SentinelForge is not a production SIEM, not a hosted service.

  • Ingest raw log files (JSON, JSONL, Sysmon) into a local SQLite database.
  • Detect using deterministic Python rules.
  • Evaluate detection performance with alert-level and event-level metrics.
  • Investigate alerts with full evidence citation.
