Installation

Install SentinelForge from source. Python 3.11+ required.

git clone https://github.com/SadashivPole/sentinelforge-ai.git
cd sentinelforge-ai
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install .
sentinelforge --help
