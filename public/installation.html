Installation

Install SentinelForge from source. Python 3.12 or newer required.

git clone https://github.com/SadashivPole/sentinelforge-ai.git
cd sentinelforge-ai
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install .
sentinelforge --help

Requirements

  • Python 3.12 or newer
  • No Streamlit, no Pandas required
  • No cloud account needed
  • Local-only execution

Run from a clean virtual environment to avoid dependency conflicts.
