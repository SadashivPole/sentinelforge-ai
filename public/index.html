Evidence-first investigation

Every SentinelForge alert is derived from preserved raw logs. The detection engine does not invent indicators — it surfaces findings that analysts can trace back to the exact source line. Humans act; the agent only surfaces.

  • Raw log preservation: Original payloads stored verbatim alongside normalized events.
  • Evidence correlation: Detections linked to source events via the evidence table.
  • No automatic remediation: The agent surfaces findings; humans decide.
  • No execution of log content: Command strings are inspected as text, never executed.

Known limitation — C2 beaconing vs benign traffic

C2BeaconRule cannot reliably distinguish benign periodic HTTPS traffic (software updates, EDR heartbeats) from low-frequency C2 beaconing. All other detection rules produced zero false positives. Analyst investigation with destination reputation and process context is required.

Installation

Get started in minutes

Python 3.12 or newer required. No Streamlit, no Pandas, no cloud account.

git clone https://github.com/SadashivPole/sentinelforge-ai.git
cd sentinelforge-ai
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install .
sentinelforge --help

Local dashboard

After ingesting data, start the read-only local dashboard:

sentinelforge dashboard --db-path data/sentinelforge.db

Binds to 127.0.0.1:8080 only. Never exposed publicly.
